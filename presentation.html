"일단 동작하게" 프롬프트

보안 컨텍스트 없이 기능 구현 최우선. 인증·검증 로직은 프롬프트에 명시하지 않으면 생성되지 않는다.

오래된 튜토리얼 데이터

LLM 훈련 데이터에는 f-string SQL, MD5 해싱, pickle 직렬화 같은 구식 패턴이 다수 포함되어 있다.

개발 예제 그대로 배포

DEBUG=True, 하드코딩 크레덴셜, verify=False 등 개발 편의 설정이 프로덕션에 그대로 올라간다.

"에러 없애줘" 프롬프트

except: pass — 에러를 조용히 삼키는 패턴. 보안 이벤트 감지 불가.

"LLM이 생성한 코드의 취약점을 스스로 경고하는 비율은 12.6%~40%에 불과하다. 모델은 자신이 만든 취약점을 대부분 인지하지 못한다."
