02 — Research Background

데이터로 증명된
반복 취약 패턴

2021~2026년 6편의 독립적 동료평가(peer-reviewed) 연구가 동일한 취약 패턴을 반복 관찰했다. SLAyer의 탐지 룰셋은 이 연구들의 공통 CWE 관측값과 자체 수집 데이터셋을 기반으로 실증적으로 선별한 7종이다.

2026 · Blain & Noiseux · arXiv:2604.05292
Broken by Default: Security of LLM-Generated Code
7개 LLM · 3,500개 코드 — GPT-4o 62.4% 취약점율. 전 모델 OWASP D등급.
"LLMs consistently fail to adhere to secure coding best practices, producing code that is broken by default."
2025 · Schreiber & Tippe
Security Vulnerabilities in AI-Generated Code
GitHub 7,703 파일 — Python 16~18.5% · 77종 CWE · JS 3.9%
"Python code contains the highest rate of vulnerabilities at 16–18.5%, with 77 distinct CWE types identified."
2025 · Samsyudin
Vibe Coding and AI-Led Programming
바이브코딩 vs 수동 직접 비교 — 잠재 취약점 22% 더 높음
"Vibe-coded projects exhibited 22% more potential vulnerabilities than manually written counterparts."
2025 · Cotroneo et al.
Human-Written vs. AI-Generated Code
50만개 샘플 비교 — AI 생성 코드가 전 지표에서 더 높은 위험도
"AI-generated code is consistently associated with higher security risk across all evaluated dimensions."
2025 · Waseem et al.
Vibe Coding in Practice: An Empirical Study
다중 프로젝트 분석 — 970개 보안 문제 감지, 44% 인증 취약
"44% of vibe-coded projects exhibited broken authentication patterns introduced by the AI generator."
2021 · Pearce et al. · IEEE S&P 2022
Asleep at the Keyboard?
GitHub Copilot 초기 분석 — ~40% 생성 코드에 CWE 취약점 포함
"We found that about 40% of the generated programs contained at least one vulnerability from the CWE top 25."
