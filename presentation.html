01 — Problem Statement

바이브코딩은 빠르다.
그리고 위험하다.

API 키 넣어서 외부 서비스 연동해줘, 빠르게
API_KEY = "sk-prod-a3f9...c22b" requests.get(url, verify=False) → GitHub 푸시 즉시 전체 공개 · MITM 공격 노출
실제 사례: API 키 노출 후 당일 클라우드 비용 $3,000 청구
유저 검색 기능 추가해줘
query = f"SELECT * FROM users
  WHERE name = '{name}'" → name에 '; DROP TABLE users; -- 입력 시 DB 전체 삭제
SQL Injection — 2024년 전체 데이터 침해의 18% 원인 (OWASP A03)
배포용으로 실행해줘, 빨리
app.run(debug=True, host='0.0.0.0') → 인터넷 전체에 Flask 디버거 오픈 · 서버 코드 원격 실행 가능
Debug mode = 원격 코드 실행(RCE) 취약점과 동일
에러 나는데 그냥 없애줘
try:
    process(data)
except:
    pass → 해커가 침투해도 로그 없음 · 이상 탐지 완전 차단
공격 인지 불가 — 침해 평균 감지 시간 207일 (IBM, 2024)

03 — Methodology

우리가 OWASP가 되는
방법

기존 보안 도구는 일반 개발자 코드를 기준으로 한다. SLAyer는 바이브코더의 코드만 대상으로 GitHub 수집 레포를 직접 분석하고, 빈도 × 중요도 합산 매트릭스로 7종을 선별한다.
