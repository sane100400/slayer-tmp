SL/Ayer

A security scanner for web service code created with AI coding tools.

It finds seven common risks, asks an installed AI CLI to patch them, then checks the code again.

Problem

AI-generated web service code often works before it is safe. Common issues include hardcoded secrets, unsafe commands, weak hashes, and debug mode left on.

What SLAyer checks

Hardcoded secrets
Unsafe network calls
Unsafe command execution
SQL without parameter binding
Debug mode in deployment
Weak hashes for passwords or tokens
Empty error handling

How it works

  • Run slayer start . to scan code.
  • Run slayer patch . to patch findings with Claude, Codex, or Gemini CLI.
  • SLAyer scans again and blocks deployment if risks remain.

Result

Before: deployment is blocked when risk is found.

After: deployment is approved only when the scan is clean.
