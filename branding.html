Why We Built This

AI-generated code has
repeated patterns

When AI generates code, it often prioritizes working behavior without security context.

As a result, analysis of many AI-generated files shows the same vulnerable patterns repeating. This comes from training data and prompt structure, not chance.

bandit uses general security rules.
SLAyer detects seven patterns common in AI-generated code.
V-01

Hardcoded credentials

API keys added "just as an example" can ship unchanged. The AI does not warn you to replace them.

V-02

DEBUG=True in production

Copy-pasted sample code can run Flask debug mode in production.

V-03

MD5 password hashing

Old tutorial code appears often in training data, so AI may choose MD5 by default.

V-04

shell=True, f-string SQL, bare except

Typical output from "make it work" or "hide the error" prompts. Existing linters miss the context.
