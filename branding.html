Brand guide

SL/Ayer

SLAyer scans web service code for common security risks and helps patch them with a local AI command-line tool.

Plain description

Use direct language. Explain the risk, the affected file, and the safe change. Avoid jokes, metaphors, and vague claims.

Colors

Dark background

Primary page background.

Risk red

Use for blocked deployment and active findings.

Safe green

Use for approved deployment and fixed findings.

Writing rules

  • Use English only.
  • Use short sentences.
  • Write for people who do not build software every day.
  • Name the exact risk and the exact safe action.

Example

NO_EXEC in app.py:27

Unsafe command execution was found. Replace shell text commands with a fixed command and separate arguments.
